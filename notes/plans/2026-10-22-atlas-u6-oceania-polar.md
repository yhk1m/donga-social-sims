# 사회과부도 아틀라스 2단계 — Ⅵ 오세아니아와 극지방 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사회과부도 Ⅵ 오세아니아와 극지방(48~55쪽)을 조각 `atlas-u6-oceania-polar`로 만들어 교사 대조표 승인 뒤 공개한다. 공개된 아시아(u2 v4)·유럽(u3 v3)·아프리카(u4 v2)·아메리카(u5 v1) 조각은 화소 하나 바뀌지 않게 지킨다 — u2~u5 네 기준선이 모두 있으므로(U5-11 끝에 u5 기준선) U6-G0 에서 `--check` 넷을 확인하고, 엔진·공유 파이프라인을 바꿀 때마다 넷 다 확인한다.

**Architecture:** 아메리카와 같다. Python(PyMuPDF)으로 PDF 글자·도형·이미지를 뽑아 `C:\Users\Public\atlas-work\`에 두고 → Node 가 앱과 같은 d3 투영(`src/atlas/fitCore.js`)으로 경위도를 맞춰 GeoJSON·지명·내용 JSON 을 만들고 → 공유 엔진(`src/atlas/`)과 공유 조립(`src/atlas/mountAtlas.js`)이 단원 조각을 그린다. 새 단원은 `scripts/atlas/units.json`에 `u6`을 더하고, 모든 명령에 `--unit u6`을 붙인다. 오세아니아·극지방에서 처음 쓰는 엔진 코드는 **모두 등록 길**(새 모듈 `src/atlas/polarExtra.js`의 `installPolarExtras()` → 이미 있는 `registerProjection`·`registerLayerType`·`registerSvgChart`·`registerFamily`)로 두어 u2~u5 조각에서 털어 낸다. 지구본·경로 화살표·우리나라 윤곽·기호 + 글자는 아메리카 것(`americasExtra.installAmericasExtras()`)을 **고치지 않고** 그대로 부른다.

**Tech Stack:** 아메리카와 같음 — Vite 6, d3-geo(+projection·polygon), csat-chart.js 2.2.2 저수준 API, PyMuPDF·numpy·shapely(≥2.1)·Pillow·rasterio, mapshaper@0.6.102, `node:test`, Python `unittest`. 새 자료(Q7 기본값일 때): Natural Earth 10m 남극 빙붕 면(U6-D).

**Spec:** `notes/specs/2026-10-20-atlas-phase2-design.md`(§5.4 Ⅵ 쪽 표, §6 새 기능 — 특히 §6.1-1 극 중심 보기·§6.1-2 지구본·§6.1-4 날짜변경선 단원 상자·§6.1-7 여러 지도 한 레이어(48쪽 하와이·타히티, 53쪽 뉴질랜드), §6.2-8 `countryClass`·§6.2-9 윤곽만 분류(배타적 경제 수역)·§6.2-15 극 부채꼴·영유권, §6.3-17 두 축 선·반원, §6.4-22 `compareOutline`, §7 위험, §8 교사 답 — 반드시 먼저 읽기), 아메리카 계획 `notes/plans/2026-10-21-atlas-u5-americas.md`(특히 「실행 중 결정」 — 이 계획의 「아메리카에서 이어받는 요령」이 그 요약), 아프리카·유럽 계획의 「실행 중 결정」(`2026-10-20-atlas-u4-africa.md` 495줄부터, `2026-10-20-atlas-u3-europe.md` 360줄부터), 1단계 계획의 「실행 중 결정」(`notes/plans/2026-10-09-atlas-asia.md` 784줄부터). 규칙: `EMBED_RULES.md`.

- **Q1 목차(주제 수)**: 설계 §5.4 어림은 주제 9(55쪽 「극지방의 중요성」 하나)다. 55쪽은 북극(항로 지구본·북극해 영유권)과 남극(남극 조약 세계 지도·남극 기지와 영유권·우리나라 극지 기지 사진·아라온호 지구본 2·주제도 활동)이 한 쪽에 몰려 있어 한 주제면 묶음이 6개가 된다. 기본값: **주제 10**(55쪽을 「북극의 지리적 중요성」 = 55쪽 ①, 「남극의 지리적 중요성과 극지 연구」 = 55쪽 ②③ + 주제도 활동으로 나눔). 50쪽 「북극」·51쪽 「남극」 일반도는 따로 된 주제 둘(극 중심 보기로 열림). 55쪽을 한 주제로 둘까?
- **Q2 오세아니아 주제는 처음부터 태평양 중심**: 48·49쪽 지도는 날짜변경선(180°)을 넘는다(키리바시·투발루·사모아·통가가 동경 180° 넘어 있음). 대서양 중심(중심 경도 0)으로 열면 이 섬나라들이 지도 왼쪽 끝으로 갈라진다. 기본값: 일반도·색칠하기·지형·기후·상호 교류(FTA 세계 지도)·환경 문제(쓰레기 섬) 주제는 **중심 경도 150 으로 연다**(다른 주제로 가면 되돌림, 지도 도구 「중심 경도」로 바꿀 수 있음). 괜찮을까?
- **Q3 48쪽 「하와이 제도」·「타히티」 삽입 지도**: 웹 지도는 확대하면 되므로 따로 창을 띄우지 않는다(아메리카 「중앙아메리카」와 같은 판단). 기본값: 두 삽입의 지명(호놀룰루·카우아이섬·마우나케아산·타히티 등)을 일반도 지명에 합쳐 **실제 자리**에 두고, 일반도 주제에 바로가기 「하와이 제도」·「타히티」(삽입 틀 범위로 날아감)를 둔다. 괜찮을까?
- **Q4 48쪽 우리나라 윤곽 — 「같은 축척과 같은 경도의 우리나라」**: 지면의 회색 실루엣은 오스트레일리아 남쪽 바다(우리나라와 같은 경도 약 125~131°E, 남위 약 33~43°)에 **남북이 뒤집힌 모양**(위도 부호만 바꾼 거울상 — 황해는 왼쪽, 동해·독도는 오른쪽 그대로)으로 놓였다. 기본값: 아메리카 Q3 답처럼 처음 자리 = 교과서 자리, 어디로든 자유롭게 끌고, 「교과서 자리로」 단추. 모양은 끌어도 거울상 그대로. 북반구로 끌면 원래 모양으로 바꿀까?
- **Q5 49쪽 색칠하기 나라 수**: 지면 글자는 초성 나라 13(ㅇㅅㅌㄹㅇㄹㅇ·ㄴㅈㄹㄷ·ㅍㅍㅇㄴㄱㄴ·ㅍㅈ·ㅅㄹㅁㅈㄷ·ㅂㄴㅇㅌ·ㅅㅁㅇ·ㅌㄱ·ㅌㅂㄹ·ㅋㄹㅂㅅ·ㄴㅇㄹ·ㅁㅅㅈㄷ·ㅍㄹㅇ) + 이름이 쓰인 나라 1(미크로네시아) = **14**(오세아니아 독립국 14 모두), 수도 ★ 14(이름이 손글씨로 쓰인 것 11 + 이름 칸이 빈 캔버라·웰링턴·포트모르즈비). 뉴칼레도니아는 노랗게 칠해져 있으나 **이름이 없다**. 괌·북마리아나·프랑스령 폴리네시아 등 속령은 글자 없음, 하와이는 지도 밖. 기본값: 퀴즈 나라 **14**, 지역(속령) 없음 — 뉴칼레도니아는 퀴즈 밖(회색, 누르면 「퀴즈에 없는 곳」), 대조표 「알려진 차이」. 뉴칼레도니아를 「지역」(수도 「—」 — 아메리카 기아나와 같은 꼴)으로 넣을까?
- **Q6 극 중심 보기의 방향과 고르기 상자**: 교과서 극 지도는 지도마다 돌린 방향이 다르다 — 50쪽 북극 = 북아메리카가 위·러시아가 아래(서경 90° 위), 51쪽 남극 = 서경 90° 위(남극반도가 위), 55쪽 「북극해를 둘러싼 영유권 분쟁」 = 알래스카가 위, 55쪽 「남극 연구 기지와 영유권」 = 세종 기지(남극반도)가 위. 기본값: **묶음마다 교과서 방향 그대로** 열고(끌기 = 지금처럼 옮기기, 회전은 고정), 지도 도구 「도법」 고르기 상자에 「북극 중심」·「남극 중심」 두 옵션을 이 단원 모든 주제에 둔다(아메리카 「지구본」과 같음 — 상자 옵션 8: 평면 5 + 지구본 + 극 둘, 극 중심에서는 「중심 경도」 단추 숨김). 고르기 상자에는 극지방 주제에서만 보이게 할까?
- **Q7 남극 빙붕(로스·론·아메리 빙붕 등)**: 교과서 51·55쪽은 빙붕을 땅처럼(흰 얼음 + 갈라진 무늬) 그렸다. 지금 바탕 지도(Natural Earth 육지)는 **빙붕을 바다로** 그린다(확인: 로스 빙붕 −175°, −81° 가 육지 밖). 기본값: Natural Earth 10m 남극 빙붕 면을 내려받아(퍼블릭 도메인, 바탕 지도와 같은 판 — U6-D) 남극 일반도·남극 기지 묶음에 「빙붕」 면 레이어(옅은 하늘빛 흰색 + 테두리, 교과서 빙붕 이름은 지명)로 둔다. 갈라진 무늬는 그리지 않음. 교과서 빙붕 도형을 되돌려 쓸까(내려받기 없음, 대신 지면 도형 정밀도에 기댐)?
- **Q8 55쪽 남극 영유권 선**: 교과서는 나라마다 색·선 모양이 다른 **경계선만**(면은 칠하지 않음) 그렸다 — 뉴질랜드 분홍 파선·칠레 빨강 점선·아르헨티나 보라 파선·영국 주황 실선·오스트레일리아 노랑 실선 둘·프랑스 초록 가는 선·노르웨이 파랑 실선(극까지 가지 않고 바깥 경계만). 기본값: 교과서 그대로 경계선만, 겹치는 영국·칠레·아르헨티나 경선은 화면에서 몇 px 비켜 그려(교과서처럼) 셋 다 보이게, 경선 값은 **교과서 선을 되돌린 값**(실제 주장 경선으로 바로잡지 않음 — 대조표에 실제 값과의 차를 참고로). 범례 고름 = 그 나라 선만 굵게. 괜찮을까?
- **Q9 과학 기지 표시**: 51쪽은 기지 약 35곳을 빨간 점 + 「이름(나라 약칭)」으로, 세종·장보고(50쪽 다산)는 태극기 그림 + 「대한민국」 붉은 글자로 그렸다. 55쪽 기지 지도는 약칭만. 기본값: 기지 = 빨간 점 + 글자(교과서 글자 그대로), 우리나라 기지 셋은 **태극기 그림 대신** 조금 큰 빨간 점 + 흰 테두리 + 「대한민국」 붉은 글자(UI 이모지·국기 그림 금지 규칙), 누르면 이름 말풍선. 55쪽 지도는 교과서대로 약칭만. 괜찮을까?
- **Q10 극 일반도의 선들 — 범례**: 50·51쪽에는 북극권·남극권(점선), 유빙 한계(물결 선), 해양 경계(붉은 선), 날짜 변경선, 빙상 두께 등고선(그린란드 1,000~3,000m · 남극 1,000~4,000m)이 지도 위 글자로만 설명되고 범례가 없다. 기본값: 선은 교과서 그대로 그리고, 웹 범례 칸에 **선 견본**(북극권·유빙 한계·해양 경계·빙상 두께)을 두어 고를 수 있게(대조표 「알려진 차이 — 교과서에 범례 없음」). 범례 없이 선만 둘까?
- **Q11 54쪽 「해양 쓰레기의 유입 경로」(삽화 막대 — 353·82·19·6·1.7 백만 톤, 0.5%)**: 값이 수백 배씩 차이 나 막대 그래프로 다시 그리면 뒤 셋이 납작해진다. 기본값: **표 카드**(단계·값·단위 — 지면 글자 그대로) + 원본 쪽 부분 보기(삽화). 막대 그래프로 다시 그릴까?
- **Q12 54쪽 「남태평양의 해수면 변화 예측」**: 작은 지도(키리바시·투발루·피지 분홍 면) + 그림 그래프(2000·2013·2050·2080·2100년 점 5개, 값 글자 없음 — 「키리바시섬 잠김」 화살표). 기본값: 작은 지도 = 환경 문제 주제의 지도 묶음(분홍 면 3 + 나라 이름), 그래프 = **잰 값 점 5개 선 그래프**(csat 선 + 점, 「잰 값 — 교과서에 수치 없음」 주석) + 원본 쪽 부분 보기(섬이 잠기는 삽화). 원본 쪽 보기만 둘까?
- **Q13 54쪽 「오스트레일리아의 무역 상대국 변화」 반원 두 개**: 1965년 27억 달러·2022년 6,706억 달러인데, 교과서 반원 반지름 비는 약 1 : 2 로 금액 비(넓이로 그리면 1965 반원이 점만 해짐)와 다르다. 기본값: **교과서 그림 크기 비 그대로**(잰 반지름) + 금액 글자, 크게 보기에서도 같음. 금액 비례(넓이)로 그릴까?
