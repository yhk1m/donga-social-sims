# 사회과부도 인터랙티브 웹 아틀라스 — 2단계 설계 (Ⅲ~Ⅵ 대륙 + Ⅰ 세계화)

작성 2026-10-20 · 대상 PDF `22개정_중학_사회과 부도_교과서_본문.pdf` (114쪽, 인쇄 쪽 = PDF 쪽) · 1단계 설계 `notes/specs/2026-10-09-atlas-asia-design.md`, 1단계 계획·결정 기록 `notes/plans/2026-10-09-atlas-asia.md`

## 1. 목표와 범위

교사 요청: 「지금 사회과부도가 아시아만 되어 있는데 다른 페이지까지 모두 개발 — 지금까지와 동일한 방식으로」.

- 2단계 = 대륙 단원 Ⅲ 유럽(26~33) · Ⅳ 아프리카(34~39) · Ⅴ 아메리카(40~47) · Ⅵ 오세아니아와 극지방(48~55) + Ⅰ 세계화 시대, 지리의 힘(8~15). 3단계(Ⅶ~Ⅻ 대한민국·지역)와 4단계(부록 통계 96~104·찾아보기 105~111)는 이 문서 범위 밖이다.
- 순서(확정): **G 파이프라인 일반화 → Ⅲ 유럽 → Ⅳ 아프리카 → Ⅴ 아메리카 → Ⅵ 오세아니아·극지방 → Ⅰ 세계화.** Ⅰ을 맨 뒤에 두는 까닭: 세계 지도 쪽은 대륙 단원에서 만든 기능(나라 단위 단계구분도, 흐름선, 지구본, 극 중심 보기)을 모두 쓴다.
- 단원 하나 = 조각 하나: `atlas-u3-europe`, `atlas-u4-africa`, `atlas-u5-americas`, `atlas-u6-oceania-polar`, `atlas-u1-world`. 각각 `npm run release`로 공개하고, 공개 전에 **교과서 대조표를 교사가 승인**해야 한다(1단계 E2와 같다).
- 「동일한 방식」 = 1단계의 모든 규칙·파이프라인·교사 결정을 그대로 잇는다(§3). 새 단원에서 처음 나오는 지도 형식만 엔진·파이프라인에 더한다(§6).

## 2. 지켜야 할 조건 (1단계와 같음)

- `EMBED_RULES.md` 전부. `npm run embed`·`check:embed` 통과가 공개 조건이다. 자료는 정적 import(fetch 금지), DOM 은 `h()`.
- 이미지(사진·원본 쪽·음영·고도 색·자연색 화상)만 같은 Pages 의 **절대 주소**로 연결한다(2026-10-08 사용자 승인 예외). 단원 이미지는 `docs/assets/atlas/<unit>/`, 공용 화상은 `docs/assets/atlas/common/`.
- 웹 타일 지도 없음. 도법 5개(밀러·메르카토르·로빈슨·구드·이퀄어스) 전환, 대서양/태평양 중심 전환은 모든 단원 공통이다. 극지방만 예외를 둔다(§6.1, 교사 질문 Q1).
- 교과서 글은 원문 그대로, 교과서에 없는 수치·사실은 넣지 않는다. 교과서 원문 문제는 앱에 넣지 않고 `content/atlas/<unit>/issues.md`에 모은다.
- UI 이모지 금지(선 아이콘), 그래프는 csat-chart.js 저수준 API 우선(없는 형식만 시험지 양식 SVG).
- PC·태블릿(1024×768 이상)만 지원. 조각 크기 목표 1~2MB, 상한 3MB(사진 제외).
- 이 PC 사정: 한글 경로에서 Node 재귀 fs(cpSync·rmSync recursive) 금지(손 순회), 중간 산출물은 `C:\Users\Public\atlas-work\`(ASCII), Python 은 `python -I`, 헤드리스 Chrome 은 `--disable-gpu --use-angle=swiftshader` + 새 user-data-dir(GPU 블루스크린 0x10E 예방).

## 4. 일반화 (G) — 단원 번호를 매개변수로

### 4.1 지금 u2 에 묶인 곳 (조사 결과)

- 이미 매개변수인 것: Python `atlas_common.UNIT_CONFIG`(env `ATLAS_UNIT_CONFIG`), Node `build_basemap`·`build_content`·`build_layers`·`build_places`·`city_controls`·`coloring_quiz`의 `CONFIG`(같은 env). 단원 설정 `config/u2.json` 안의 경로(`maps: ../maps_u2.json`, `out: sims/atlas-u2-asia/data`, `content/atlas/u2/*`, `docs/assets/atlas/u2`, `@work/tables/charts-u2.json`)도 설정에서 읽는다.
- 코드에 박힌 것:
  - `georef-cli.mjs` — `maps_u2.json`을 직접 읽음(설정 `maps`를 거치지 않음).
  - `compare.mjs` — `config/u2.json`·`maps_u2.json`·`sims/atlas-u2-asia/data`·`content/atlas/u2/photos.json`·`tables/charts-u2.json`·`compare-u2.html`·`docs/assets/atlas/u2/page`, 그리고 아시아 전용 분기(`p17-labels`, `layer-p22-singapore`, `layer-p23-density-cities`, `layer-p24-trade`, `MAIN_MAP` 표).
  - `compare_shots.mjs` — `sims/atlas-u2-asia/data/topics.json`, `/sims/atlas-u2-asia/?topic=`, 출력 `shots/e2`, 아시아 전용 장면(싱가포르 확대 창·100% 막대·세계유산 퀴즈 등).
  - `build_content.mjs` — 생성하는 `layers.js` 머리 주석 글자에 `sims/atlas-u2-asia`.
  - `sims/atlas-u2-asia/main.js` — 조립 코드 전체 + 아시아 전용 상수(`BOUNDS_OF`·`CENTER_LON_OF`·`INSETS`·`BASE_COLOR`·`LOCATORS`).
  - `src/atlas/tint.js` — 고도 색 표가 `config/u2.json tint`와 같은 값(공용 화상이라 단원과 무관 — 그대로 둠).
  - 테스트 18개 파일이 `sims/atlas-u2-asia/data/*`·`config/u2.json`·`maps_u2.json`·`content/atlas/u2/*`을 직접 읽음.
- 작업 폴더에서 단원끼리 부딪칠 이름: `text/topics-check.json`, `geo/city-holdout.json`, `shots/e2/`, `compare-u2.html`, `tables/charts-u2.json`(이름에 u2 가 있어 괜찮음). 지도 id 가 `p<쪽>-<이름>`이라 `vec/<id>.*`·`geo/<id>.fit.json`·`text/places-<id>.json`·`text/pNNN.json`은 단원이 달라도 부딪치지 않는다. `tables/climate-world.json`(97쪽 표)·`tables/index.json`(찾아보기)은 모든 단원이 함께 쓴다.

### 4.2 방식

- **단원 표** `scripts/atlas/units.json` (사람이 쓰는 설정):
  ```json
  { "u2": { "sim": "atlas-u2-asia", "title": "Ⅱ. 아시아", "pages": [16, 25], "config": "config/u2.json" },
    "u3": { "sim": "atlas-u3-europe", "title": "Ⅲ. 유럽", "pages": [26, 33], "config": "config/u3.json" } }
  ```
- **단원 고르기 한 곳**: Node `scripts/atlas/unit.mjs`(`resolveUnit(argv, env)` → `{id, sim, pages, configPath, config, mapsPath, dataDir, contentDir, assetDir, workDir}`), Python `atlas_common.unit()`이 같은 규칙으로 고른다. 우선순위 = 명령줄 `--unit uN` → env `ATLAS_UNIT` → env `ATLAS_UNIT_CONFIG`(옛 방식, 그대로 받음) → 기본 `u2`. 기본이 u2 라 지금 명령은 하나도 바뀌지 않는다.
- **단원별 파일 배치** (u2 는 지금 이름 그대로, 새 단원은 같은 꼴):
  ```
  scripts/atlas/config/uN.json        단원 설정(레이어·지명·사진·그래프·바탕 지도·내용 — u2 와 같은 키)
  scripts/atlas/maps_uN.json          단원 지도 목록(설정 maps 가 가리킴)
  content/atlas/uN/                   topics.json · overrides.json · photos.json · coloring.json · issues.md
  sims/atlas-uN-<slug>/               index.html · main.js(단원 자료 import + 단원 선택값만) · data/*.json(생성물)
  docs/assets/atlas/uN/               photo/ · page/ · overlay/
  $ATLAS_WORK/units/uN/               단원 단위 작업 파일(topics-check·city-holdout·charts·shots·compare.html)
  ```
  u2 설정 파일은 G 동안 **얼린다**(바꾸지 않음). 설정 일부의 해시가 생성물 도장(`meta.inputsHash`, `content.stamps`)에 들어가 있어서, u2 설정을 고치면 u2 생성물이 바이트 단위로 달라지기 때문이다. 그래서 단원 작업 파일 경로는 새 설정 키(없으면 지금 u2 경로)로 받고, u2 는 지금 경로를 그대로 쓴다.
- **공유하는 것 / 단원마다 따로인 것**:

  | 공유 | 단원마다 |
  |---|---|
  | 엔진 `src/atlas/*` 전부(렌더러·레이어·범례·그래프·퀴즈·주제 펼치기·화면 부품) | `config/uN.json`, `maps_uN.json` |
  | 조립 `src/atlas/mountAtlas.js`(새로 — 지금 main.js 본문을 옮김) | `sims/atlas-uN-*/main.js`: 자료 import + 선택값(`boundsOf`·`centerLonOf`·`insets`·`baseColor`·`locators`·`unitBoxes`) |
  | 공용 화상 `docs/assets/atlas/common/`(음영 `relief-4096.jpg`·고도 색 `tint-4096.png`·자연색 `natural-4096.jpg`) — 전 지구 등장방형이라 모든 단원·극지방에도 그대로 | 바탕 지도 `basemap.json`(110m·50m 전 지구 + 그 단원 상자 10a — 조각에 넣어야 하므로 단원마다 생성) |
  | 파이프라인 코드 `scripts/atlas/*`(단원 번호만 받음) | 지명 `places.json`, 레이어 `layer-*.json`, `topics.json`·`charts.json` |
  | 97쪽 기후 표 `tables/climate-world.json`, 찾아보기 `tables/index.json`, Natural Earth 원본(`raw/ne`) | 사진·원본 쪽 이미지 |
  | 고도 색·자연색 설정 — u2 설정의 `tint`·`natural`에 남겨 두고, `build_tint.py`·`build_natural.py`는 그 절이 없는 단원 설정이면 「공용 화상은 u2 설정으로 만든다」고 알리고 멈춘다 | 대조표 장면·확인 목록 `config/uN.compare.json`(u2 설정을 얼리려고 단원 설정과 따로 둠) |

- **조립 공유**: `mountAtlas(root, { simId, basemap, places, topics, charts, layers, insets, boundsOf, centerLonOf, baseColor, locators })` → `{ destroy }`. 개발 매개변수(`?topic=&proj=`)·확인용 `root.atlas*` 노출도 여기로 옮긴다. 단원 main.js 는 정적 import 와 이 호출뿐이다(fetch 를 못 쓰니 import 는 단원 파일에 있어야 한다).
- **대조표 일반화**: `compare_shots.mjs --unit uN`(장면 = 주제마다 기본 + 묶음마다 + 설정 `compare.extraScenes`), `compare.mjs --unit uN`(아시아 전용 분기는 `config/uN.compare.json`의 `checks`로: 색칠하기 글자 파일, 확대 창 레이어, 범례 없는 기호 레이어, 주제별 대표 지도 `mainMap`, 도법·중심 확인).
- **테스트**: 엔진 순수 함수 테스트는 그대로. 단원 자료 테스트는 ① 지금 u2 테스트를 그대로 두고(회귀 보호) ② 단원 공통 계약 테스트 `tests/atlas/unitContract.test.mjs`를 더해 `units.json`의 생성물이 있는 단원마다 돈다(주제 쪽 범위 덮음·참조 레이어·사진·그래프 존재·빈 글 없음·용량 상한·설정 기대 수). 단원 고유 수치(기호 수 등)는 `config/uN.json expect`에서 읽는다.
- **회귀 증명**: G 를 시작하기 전에 u2 산출물의 해시와 대조표 캡처(41장)·대조표 결과(다름 0·알려진 차이 9·같음 134·참고 24)를 기준선으로 저장한다. G 끝에 u2 파이프라인을 처음부터 다시 돌려 ① `sims/atlas-u2-asia/data/*`·`content/atlas/u2/*`·`docs/assets/atlas/**`·작업 폴더 핵심 산출물(fit·features·places·charts)이 **바이트까지 같고** ② 조각(`embed/atlas-u2-asia.html`)은 코드 위치만 바뀐 것이 정당한 차이로, 캡처 41장 화소 비교 같음 + 대조표 결과 같음 + `npm test` 통과 + 조각 크기 ±1% 안이어야 한다.

### 5.1 Ⅲ 유럽 (26~33) — 조각 `atlas-u3-europe`

| 쪽 | 내용 |

## 6. 새로 필요한 엔진·파이프라인 기능 (아시아에 없던 것)

처음 쓰는 단원에서 만들고, 뒤 단원은 그대로 쓴다. 모두 기존 레이어 계약(`{id, z, draw, drawSvg, hit, destroy, labelObstacles}`)·범례 상태·설정 주도 방식을 따른다.

### 6.1 보기·도법

1. **극 중심 보기 (Ⅵ, 50·51·55쪽)** — 밀러·메르카토르(±85°)·로빈슨·구드·이퀄어스는 극지방을 가장자리에 납작하게 그린다. 극지방 주제만 6번째 보기 「극 중심(정거 방위)」(`polarN`·`polarS` = `geoAzimuthalEquidistant().rotate([0, ∓90])`, 반구 맞춤)를 더한다. 극 보기와 원통·의사원통 도법 사이 전환은 보간 대신 짧은 페이드(중심 경도가 정의되지 않음), 대서양/태평양 단추는 극 보기에서 숨김. 렌더러의 화면 밖 미리 자르기·`fitBoundsTransform`·축척 막대·`kmPerPx`·음영/고도 색/자연색 역투영 격자는 투영 독립이라 그대로 동작해야 한다(테스트로 확인). → 교사 질문 Q1.
2. **지구본(정사 도법) (Ⅴ 46쪽 인구 이동, Ⅵ 55쪽 북극 항로·아라온호, Ⅰ 9·11쪽 대륙·대양 지구본, 14쪽 작아지는 지구)** — 자료가 있는 지구본(46·55쪽)은 주제 보기 「지구본」(`geoOrthographic`, 끌면 회전, 클립 90°)으로 그리고, 그림뿐인 지구본(9·11·14쪽)은 사진 카드 또는 바로가기 단추(누르면 그 대륙·대양으로 날아감). → 교사 질문 Q2.
3. **도법 맞추기 후보 추가** — `fitCore.FAMILIES`에 `stereographic`(40·41쪽 입체 투영), `orthographic`(지구본), 극 방위(`azimuthalEquidistant` 매개변수 위도 ±90 고정형). **주의**: `fitControls`는 모든 후보 중 가장 잘 맞는 것을 고르므로 후보를 더하면 u2 지도 fit 이 바뀔 수 있다 → 지도 항목·단원 설정에 `families`(허용 후보)를 두고, u2 는 지금 8개 그대로(G 에서 기본값 고정 + 테스트).
4. **날짜변경선을 넘는 단원 상자 (Ⅵ 48쪽)** — `unitBoxes`가 이미 여러 상자(추코트카)를 받으므로 `[[110, -50, 180, 10], [-180, -50, -130, 25]]`꼴로 쓴다. 레이어 선 나누기·`joinParts`·`fitBoundsTransform`(e < w)은 있음 — 오세아니아 보기·하와이 확대·피지 근처에서 이음매 확인 캡처를 더한다.
5. **두 쪽에 걸친 지도 (Ⅰ 8~9·10~11쪽)** — PDF 쪽마다 따로 fit(`p08-world`, `p09-world`)하고, 지명·레이어는 쪽 가름선 근처 겹침을 합친다(places 합치기 규칙에 `spreadOf` 묶음). 같은 도법·축척이므로 두 fit 의 매개변수 차가 작아야 한다(검증 항목).
6. **삽입 지도 fit 공유 (Ⅴ 46쪽 미국 4장 × 알래스카·하와이)** — 같은 배치의 삽입이 여러 지도에 반복된다. maps 항목 `fitFrom: <다른 지도 id>` + 쪽 이동량으로 기준점을 한 번만 적는다. 웹에서는 알래스카·하와이를 **실제 위치**에 그린다(웹 지도라 삽입 불필요 — 기본값, 대조표 「알려진 차이」).
7. **여러 지도를 한 레이어로 (Ⅲ 29쪽 아이슬란드, Ⅵ 53쪽 뉴질랜드, Ⅴ 40쪽 중앙아메리카, Ⅵ 48쪽 하와이·타히티)** — 레이어 설정 `maps: [본 지도, 삽입…]`이면 각자 fit 으로 되돌려 한 GeoJSON 으로 합치고, 겹친 곳은 큰 축척(삽입) 우선.

### 6.2 레이어

8. **나라 단위 단계구분도 `countryClass` (Ⅲ 30·32쪽, Ⅳ 39쪽, Ⅰ 14·15쪽, Ⅵ 54·55쪽 등)** — 나라 하나가 한 색인 지도는 교과서 채움 도형을 따라 그리지 않고, Natural Earth 나라마다 안쪽 표본점 여러 개를 fit 으로 지면에 찍어 그 자리 채움색(벡터 우선, 래스터면 화소)을 범례색(Lab ΔE)과 대조해 다수결로 분류한다. 생성물은 `{iso: cls}`(수 KB)이고 웹은 바탕 지도 나라 도형을 칠한다. 장점: 용량이 아주 작고 나라 경계가 바탕 지도와 꼭 맞음. 대조표에 나라별 분류표를 넣고, 교과서와 Natural Earth 의 나라 단위가 다른 곳(서사하라·코소보·북키프로스·소말릴란드·그린란드·프랑스령 기아나 등)은 설정 `countryOverrides`{iso: {cls, why}}. 아시아의 23·24쪽 레이어는 지금 방식 그대로 둔다(회귀).
9. **윤곽만 분류 (Ⅲ 32쪽 유로 사용국 노란 테두리, Ⅵ 55쪽 배타적 경제 수역 점선, Ⅳ 39쪽 그레이트 그린 월 띠)** — 범례 항목 `style: 'outline'|'line'`. 면을 칠하지 않고 테두리만, 범례 고름은 윤곽 굵게.
10. **무늬 채움 확장 (Ⅳ 38쪽 공용어 둘인 나라, Ⅴ 46쪽 혼혈, Ⅳ 39쪽 사하라 점무늬·사헬 빗금)** — 아시아의 `pattern: 'hatch'`(고산 기후)를 넓혀 `pattern: {type: 'stripes', colors: [a, b], angle}`·`{type: 'dots', color}`. 두 색 줄무늬 나라는 범례 두 분류 모두에 속한다(고르면 둘 중 하나만 맞아도 남김).
11. **지도 위 그래프 기호 (Ⅳ 38쪽 자원 고리 7, Ⅴ 46쪽 민족 고리 5)** — `chartSymbolLayer`: 경위도 자리에 작은 고리(교과서 색·값, 가운데 글자), 지시선, 누르면 사이드바에 같은 그래프를 크게. 확대 단계별 크기는 기호 레이어 규칙(`symbolPx`)을 따른다.
12. **크기 비례 기호와 범례 (Ⅲ 30쪽 도시 인구 5단계, Ⅴ 47쪽 본사 원 크기, Ⅳ 39쪽 원 크기 그래프, Ⅴ 47쪽 네모 단위 기호)** — 기호 레이어에 `sizeBy: {classes | sqrt(value)}`, 범례에 겹친 원 견본(`legendStyle: 'nested-circles'`), 네모 단위(1칸 = 50개 공장 등)는 아시아 인구 막대(`shape: 'bar'`) 꼴을 넓혀 `shape: 'units'`.
13. **값 붙은 기호 (Ⅲ 31쪽 리스본 전기차 충전소, Ⅴ 47쪽 D사 지역별 개수, Ⅵ 51쪽 기지 나라 약칭)** — 기호 옆에 교과서 수치·약칭 글자(지명 배치기의 장애물·우선순위 규칙 사용).
14. **흐름선 대량·대권 (Ⅰ 14쪽 인천 항공망 약 80+, Ⅴ 46쪽 이동 화살표, Ⅵ 55쪽 항로)** — 기존 `flowLayer`(이차 베지어·화살촉)를 대권 경로(`geoInterpolate`) 선택지와 묶음 굵기 하나(범례 없음)로 넓힌다. 80+ 선 SVG 성능 측정.
15. **극 부채꼴·영유권 (Ⅵ 55쪽)** — 남극 영유권 부채꼴(경선 두 줄 사이 면)은 교과서 도형을 극 fit 으로 되돌린다. 극점을 포함하는 면은 d3 감김 방향·남극 육지 자르기에 주의(테스트: 극점 포함 면 면적·포함 판정).
16. **세계 래스터 분류 (Ⅳ 38쪽 태양광 잠재력, Ⅰ 13쪽은 벡터)** — 아시아 21쪽 래스터 분류(Lab ΔE + 체로 거르기)를 세계 범위에 그대로. 큰 화상이라 용량 상한(레이어별 tol·minArea) 조정.

### 6.4 퀴즈·활동
