# 사회과부도 인터랙티브 웹 아틀라스 — 설계 (1단계: 지도 엔진 + Ⅱ 아시아)

작성 2026-10-09 · 대상 PDF `22개정_중학_사회과 부도_교과서_본문.pdf` (114쪽, 인쇄 쪽 = PDF 쪽)

## 1. 목표와 범위

동아출판 중학 사회과부도 전체를 웹 아틀라스로 옮긴다. 레퍼런스는 GeoStatAtlas(오른쪽 사이드바 + 지도, 범례 = 필터, OSM 바다색, 대서양/태평양 중심 전환).

- 사용자 허락: 부도의 사진·글·데이터를 모두 사용할 수 있다.
- 전체 계획(단계별로 따로 설계·구현·공개):
  1. **지도 엔진 + Ⅱ 아시아(16~25쪽)** ← 이 문서
  2. 나머지 대륙 단원(Ⅲ~Ⅵ), Ⅰ 세계화
  3. 대한민국·지역 단원(Ⅶ~Ⅺ), Ⅻ 지속가능
  4. 부록(통계 96~104, 찾아보기 105~111), 퀴즈 확장
- 이번 단계 완료 기준: `/atlas-u2-asia/1` 공개. 이때 아시아 10쪽의 지도·주제도·사진·그래프·글이 모두 들어 있고, 사용자가 교과서 대조표를 승인한 상태여야 한다.

## 2. 지켜야 할 조건

- `app/EMBED_RULES.md` 전부(래퍼 div 하나, 범위 지정 CSS, innerHTML·fetch·import()·Worker·data:/blob: URL 금지 등). `npm run embed` 검사 통과가 공개 조건이다.
- **예외(2026-10-08 사용자 승인)**: 사진·그림·지형 음영 같은 이미지는 같은 GitHub Pages(`https://yhk1m.github.io/donga-social-sims/assets/atlas/…`)에 파일로 올리고, **절대 주소** `<img>`/`Image`로 연결한다. 이미지 말고는 모두 조각 안에 넣는다.
- 웹 타일 지도(OSM 등)는 쓰지 않는다. d3 지도로 웹지도에 준하는 느낌을 낸다.
- 도법: **밀러, 메르카토르, 로빈슨, 구드(단속 호몰로사인), 이퀄어스** 다섯 개 사이를 전환할 수 있어야 한다.
- 공통 셸: 헤더·푸터 없음, 왼쪽 무대 + 오른쪽 사이드바(`createShell`, `h()`, `addBlock`). PC·태블릿(1024×768 이상, 세로 768은 사이드바가 아래로)만 지원하고 휴대폰은 고려하지 않는다.
- UI에 이모지는 쓰지 않고 선 아이콘만 쓴다. 그래프는 csat-chart.js(`renderLineGraph` 등 저수준 API만, 글꼴 불러오기 코드 제외)를 우선 쓴다.
- 배포: 기존 저장소 `yhk1m/donga-social-sims`, `npm run release`로 버전을 고정한다(`/<id>/<n>`, 옛 버전 영구 유지).

## 3. 구조

```

    projections.js           5개 도법 정의·전환·중심 경도
    renderer.js              캔버스 바탕층 + 상호작용층, 확대 단계별 상세도
    labels.js                지명 배치(우선순위·충돌 회피·확대 단계별 표시)
    relief.js                지형 음영 이미지 재투영(실패 시 생략)
    layers.js                주제 레이어 종류: 면 분류(choropleth/구역), 기호, 흐름선, 마커, 이미지 레이어
    legend.js                범례 = 필터 (클릭 시 해당 분류만 남김)
    ui.js                    목차·주제 전환·카드·「원본 쪽 보기」
    charts.js                csat-chart.js 래퍼(선·막대·누적 막대·피라미드·원)
  sims/atlas-u2-asia/        단원 조각: mount(root) + 단원 자료 import
  content/atlas/u2/*.json    주제별 내용(글·마커·사진 경로·숫자) — 사람이 고칠 수 있는 원본
  scripts/atlas/             추출 파이프라인(단원 공통, 단계별 스크립트)
  docs/assets/atlas/u2/      공개 이미지(사진, 원본 쪽 이미지, 음영·밀도 이미지)
```

- registry: `{ id: 'atlas-u2-asia', book: 'atlas', unit: 'Ⅱ. 아시아', page: 16, title: '사회과부도 아시아', kind: '지도' }`
- 단원 조각 크기 목표는 1~2MB(사진 제외)다. 3MB를 넘으면 상세도·지명 수를 줄인다.

## 4. 지도 엔진

- **도법**: d3-geo(`geoMercator`, `geoEqualEarth`)와 d3-geo-projection(`geoMiller`, `geoRobinson`, `geoInterruptedHomolosine`). 전환할 때 화면 중심 경위도와 확대 수준을 유지한 채 0.6초 동안 보간한다. 중심 경도는 대서양(0°)과 태평양(150°E)으로 전환할 수 있다. 메르카토르는 ±85°에서 자른다. 구드는 단속선이 대륙을 가르지 않도록 기본 단속 위치를 쓰고, 그린란드·남극처럼 찢어지는 곳은 그대로 둔다.
- **그리기**:
  - 바탕층(캔버스): 바다(OSM 계열 `#aad3df`) → 지형 음영 → 육지 → 주제 면 → 호수·하천 → 국경 → 경위선
  - 상호작용층(SVG): 마커·흐름선·선택 강조·지명
  - 확대·이동 중에는 바탕층을 변환만 하고, 멈추면 다시 그린다.
- **확대 단계별 상세도**: 세계 Natural Earth 110m, 확대하면 50m, 단원 지역(아시아 범위)은 10m에서 잘라 쓴다. 단원 범위 밖은 50m까지만 쓴다.
- **지명**: 교과서 일반도(16·18·19쪽)의 지명을 경위도·글자 크기·종류(나라/수도/도시/산맥/하천/바다)와 함께 쓴다. 우선순위가 높은 것부터 겹치지 않게 놓고, 글자 크기 등급에 따라 확대 단계별로 나타나게 한다. 흰 테두리(halo)를 두른다.
- **지형 음영**: 공개 음영기복도(Natural Earth Shaded Relief, 등장방형 이미지)를 Pages에 올리고, 화면 픽셀마다 역투영해 캔버스에 그린 뒤 멈출 때마다 갱신한다. 이미지 픽셀을 읽지 못하면(교차 출처 차단 등) 음영을 생략하고 나머지는 정상 동작한다.
- **조작**: 끌기, 휠, 두 손가락 확대, 확대/축소/전체 보기 버튼, 축척 막대(도법·위도에 맞게), 경위선과 지명 켜고 끄기, 대서양/태평양 전환. 확대 범위는 1~40배.
- **선택**: 나라·구역·마커를 누르면 강조 테두리를 두르고 사이드바에 상세를 띄운다. 마우스를 올리면 이름 말풍선을 무대 안 absolute 위치에 띄운다.

## 5. 아시아 단원 내용 (주제 = 사이드바 목차)

## 6. 추출 파이프라인 (`scripts/atlas/`)

조사 산출물 `C:\Users\Public\atlas-survey\`(복원기 `dec.py`, `spans.json`, 쪽 렌더)를 출발점으로 쓴다. 이 PC에서는 한글 경로에 출력하면 Node가 죽을 수 있으므로, 중간 산출물은 ASCII 경로(`C:\Users\Public\atlas-work\`)에 두고 최종 결과만 저장소로 복사한다.

1. **글자 복원**: 쪽별 글자를 위치·크기·글꼴과 함께 복원하고, 쪼개진 지명·자간 벌린 글자를 합친다.
2. **경위도 맞추기**: 지도마다 경위선 교차점과 테두리 눈금 숫자로 기준점(지면 xy ↔ 경위도)을 만든다. 후보 투영식(정거/정적 방위, 원추, 밀러, 로빈슨 등)의 매개변수를 최소제곱으로 맞추고, 잔차가 크면 thin-plate spline으로 보정한다.
   - 검증: 맞춘 식으로 Natural Earth 해안선을 지면에 투영해 교과서 해안선과 비교한다. **지면 기준 평균 0.5mm 이내**여야 통과다.
3. **주제 면**: 지도 영역의 채움 도형을 범례 견본 색과 대조해 분류하고, 경위도 도형으로 바꿔 Natural Earth 육지로 자른 뒤 단순화한다.
4. **지명**: 일반도 글자를 경위도와 등급으로 바꾸고, 찾아보기(105~111쪽)와 대조해 철자·누락을 확인한다.
5. **이미지**: 사진·그림 영역을 원본 해상도(약 150dpi)로 렌더링해 잘라 낸다(조각난 타일은 위치 기준으로 합친다). WebP와 JPEG를 함께 만들고 짧은 변 기준으로 크기를 정한다. 원본 쪽 이미지는 쪽마다 1장씩 만든다.
6. **그래프 숫자**: 그래프에 인쇄된 숫자, 막대·선 도형 높이, 부록 통계표를 쓴다. 출처와 기준 연도를 함께 기록한다.
7. **내용 JSON**: 1~6의 결과를 `content/atlas/u2/<주제>.json`으로 모은다. 사람이 고친 값은 다음에 추출을 다시 돌려도 덮어쓰지 않는다(`overrides`를 따로 둔다).

## 7. 검증

- 자동:
  - `npm run embed -- atlas-u2-asia` 규칙 검사 통과
  - 경위도 맞추기 잔차 보고서(지도별)
  - 개수 대조: 지형 핀 8, 기후 그래프 5, 세계유산 11, 일반도 3 바로가기 등 조사 목록과 일치
  - 내용 JSON 스키마 검사(빈 글·없는 이미지 경로 금지)
- 대조표: 주제마다 「교과서 쪽 | 웹 화면(같은 범위)」 캡처를 나란히 놓은 HTML 대조표를 만든다. 사용자가 보고 승인한다.
- 성능: 1024×768에서 확대·이동 중 프레임 시간, 도법 전환 시간, 조각 크기를 측정한다.
- 이미지 경로: 공개 후 모든 `<img>` 주소가 200을 돌려주는지 확인하고, 다른 출처 페이지에 붙였을 때 음영이 나오는지(또는 생략되는지) 확인한다.
