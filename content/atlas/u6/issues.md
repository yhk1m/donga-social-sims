# Ⅵ 오세아니아와 극지방(48~55쪽) — 교과서 원문에서 발견한 문제 (사용자 확인용)

앱에는 교과서에 인쇄된 그대로 넣습니다. 교과서 자체에 주석이 없으므로 앱에 별도 알림을 달지 않습니다. 바로잡을지는 사용자가 정해 주세요.

「**교과서 담당자 확인 필요**」 표시가 붙은 항목은 교사가 앱은 지금대로 두고 교과서 담당자에게 확인을 받기로 한 것입니다(교사 답 2026-10-23 — 대조표에도 같은 표시). 학생 화면에는 이 표시를 넣지 않습니다.

## 지도 (U6-2에서 발견 — 후보)

1. **55쪽 「세계 각국의 남극 연구 기지와 영유권 분쟁」 지도의 축척 막대 「200km」가 지도 크기와 맞지 않습니다.** 막대 길이는 13.9pt(약 4.9mm)인데, 이 지도의 경위선(남위 80°·70° 원과 30° 간격 경선 — 벡터 선)으로 잰 축척은 위도 10°(약 1,112km)가 24.1pt라 1pt ≈ 46km입니다. 막대가 나타내는 거리는 약 640km이고, 200km 막대라면 길이가 약 4.3pt(1.5mm)여야 합니다(축척 약 1:1억 3천만). 같은 쪽 「북극해를 둘러싼 영유권 분쟁」 지도의 「1000km」 막대(19.2pt → 1pt ≈ 52km)는 지도 축척(1pt ≈ 49km)과 맞습니다. 앱은 인쇄된 그대로 둡니다(경위도 맞추기는 축척 막대를 쓰지 않음 — 결정 기록 U6-2).
   - **교과서 담당자 확인 필요** — 교사 답: 인쇄된 그대로 두고 담당자에게 확인.

## 그래프 (U6-7에서 발견 — 후보)

2. **53쪽 퍼스·크라이스트처치 기후 그래프가 97쪽 「주요 도시의 기후」 표와 다르게 그려졌습니다.** 같은 틀·같은 눈금 자리인데(같은 쪽 다윈 그래프는 표와 차 0.3℃ 안), 그림의 기온 점은 표보다 7~8℃ 높고(퍼스 1월 표 24.7℃ ↔ 그림 약 32.9℃, 크라이스트처치 1월 표 16.8℃ ↔ 그림 약 24.2℃), 강수 막대도 약 10% 높습니다(퍼스 7월 표 137.1mm ↔ 그림 약 151.9mm, 크라이스트처치 7월 표 67.6mm ↔ 그림 약 73.6mm). 앱은 표에 인쇄된 값으로 그래프를 그리므로 앱 그래프가 교과서 그림보다 낮게 보입니다(결정 기록 U6-7).
   - **교과서 담당자 확인 필요** — 교사 답: 97쪽 표 값을 그대로 쓰고 담당자에게 확인.
3. **53쪽 앨리스스프링스 기후 그래프의 오른쪽 강수 눈금에 「350」이 두 번 인쇄되었습니다.** 아래에서 아홉째 눈금(400 자리)에 「350」이 한 번 더 찍혀 있어 400 이 빠졌습니다. 앱은 그 눈금을 400 으로 읽어 그래프 값을 잽니다(앨리스스프링스는 97쪽 표에 없어 그림을 잰 값).
   - **교과서 담당자 확인 필요** — 교사 답: 400 으로 읽는 것이 맞음, 담당자에게 확인.

## 지도 (U6-8에서 정리 — 후보)

4. **53쪽 「오세아니아의 기후 구분」 지도의 파푸아 뉴기니 고지대에 범례에 없는 빗금(초록 사선)이 있습니다.** 범례는 열대 3·건조 2·온대 4 = 9칸이고 빗금 칸은 없습니다. 고산 기후를 나타낸 것으로 보입니다. 앱은 교과서 그대로 빗금을 그리고, 교사 답(2026-10-23)에 따라 웹 범례에 「고산 기후(빗금)」 견본을 더했습니다(처음에는 Q15 기본값대로 범례에 넣지 않았음 — 결정 기록 U6-4·U6-10t).
